# Dashboard methodology

The profile dashboard is generated by `scripts/update_profile.py` using the GitHub REST API. SVGs are stored in this repository, so the profile does not depend on a third-party statistics image service. Both light and dark themes have a compact mobile layout. An accessible text version is included in the profile README.

- **Public projects:** public repositories owned by Eraj-Choriev, excluding forks and the profile repository itself. Archived public repositories remain included. Private repositories and their metadata are never collected.
- **Primary languages:** GitHub's primary language classification per included repository. Repositories with no classified language are omitted from the language chart. This is a repository count, not code volume, developer expertise, or time spent.
- **Linked demos:** included repositories with a non-empty homepage field. This measures published links; it does not claim every deployment is always online.
- **Public commits:** commits returned by the default-branch commit endpoint with `author=Eraj-Choriev`, using author dates. The chart covers the current calendar week and the preceding eleven weeks, in Asia/Dushanbe. The current week is incomplete. Commits without attribution to this GitHub account and commits on other branches are outside this metric. It is not GitHub's contribution calendar, which also includes other activity.
- **Active days:** distinct commit author dates within that same public commit dataset.

All three featured project previews returned HTTP 200 when the profile was prepared. Token Lens is described as a dashboard interface, without claiming its demo data represents real production usage.

The refresh runs daily at 02:17 UTC (07:17 Asia/Dushanbe) and can be triggered manually in GitHub Actions. Scheduled jobs may start later than their target time. GitHub may disable scheduled workflows in a public repository after 60 days without repository activity; a manual run or a new commit can restore operation. If a GitHub request or pagination check fails, the script exits with an error before replacing the existing snapshot. The images retain their last successful update date.

The workflow uses the repository's standard `GITHUB_TOKEN` and `contents: write` to commit generated files to this profile repository. No personal access token, private repository access, or paid API is required. The only action is the official GitHub checkout action pinned to its inspected v4 commit.

To reproduce the current images without network requests:

```sh
python3 scripts/update_profile.py --snapshot data/public.json
```

Sources: [Profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme), [repository API](https://docs.github.com/en/rest/repos/repos), [commit API](https://docs.github.com/en/rest/commits/commits).
